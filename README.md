# Retrospective Board

This is a real-time retrospective board built with React, Vite, Tailwind CSS, and Supabase.

## Features
- Real-time card updates across all users.
- Drag and drop cards within and between boards.
- Config-driven board names and styles.

## Tech Stack
- **Frontend:** React (TypeScript) + Vite
- **Styling:** Tailwind CSS (v4)
- **Backend/DB:** Supabase (PostgreSQL + Realtime)
- **DND:** @dnd-kit

## Deployment
This project is set up to deploy to GitHub Pages via GitHub Actions.
